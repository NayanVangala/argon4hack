# Scene Pitch Package

For the Gemini 4 Argon hackathon, Oct 25, 2026, San Francisco. Feature freeze 7:30 PM PDT, submission 10:00 PM PDT.

This folder contains only the pitch package. No code, no keys, no credentials.

## Files

- [PITCH-SCRIPT.md](PITCH-SCRIPT.md) - 3-minute pitch script, no slides, rubric-mapped with time marks 0:00-3:00. Includes the promises problem, the spine (Scene watches your day, Argon understands the whole day at once, it makes sure you follow through), the no-retrieval line said out loud, the real verification loop (Critic, quote verification by code, needs_review, nothing sends without a tap), and demo beats in order (glasses recording, scenes appearing, Ask with verbatim receipts, follow-up approve tap), plus a one-line fallback if glasses fail live.
- [VIDEO-SHOT-LIST.md](VIDEO-SHOT-LIST.md) - 60-second uncut lens video shot list, second by second, no cuts, no edits. Shows pin, timeline scroll, back, and a live scene appearing, with setup notes and restart-the-take rules if a shot fails.
- [SUBMISSION-CHECKLIST.md](SUBMISSION-CHECKLIST.md) - Submission fields checklist with honest ready / in-progress / to-confirm status per field, including project description, Google products used, team, repo URL, demo video, and rule reminders.
